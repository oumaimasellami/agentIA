Graph Information

This graph visualizes the dependency relationships in the NRT system. Click on nodes to highlight their connections, drag to reposition, and use the controls to navigate.

Node Types: Commits represent code changes, Microservices are system modules, Functions are implementations, and WorkItems are user requirements.

Edges: Lines represent relationships: MODIFIES (commits → microservices), IMPLEMENTS (microservices → functions), and COVERS (functions → workitems).
